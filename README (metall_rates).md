# Анализ цен на цветные металлы

Этот скрипт выполняет обработку и анализ данных о ценах на цветные металлы (медь, алюминий, олово, никель), собранных с сайта [monetka.com.ru](https://monetka.com.ru/quotes-metal/).  
Он позволяет автоматически рассчитать ежемесячные средние значения и динамику изменения цен.

## 📄 Описание

Скрипт читает Excel-файл, в котором на отдельных листах (`Медь`, `Алюминий`, `Олово`, `Никель`) содержатся данные по каждому металлу.  
Каждый лист должен включать две колонки:
- **Дата**
- **Цена**

После обработки данных программа:
- Преобразует даты в формат `YYYY-MM-DD`;
- Очищает значения цен;
- Рассчитывает **средние месячные цены** для каждого металла (исключая текущий месяц);
- Добавляет **последние доступные котировки**;
- Вычисляет **динамику изменения цен (%)** между последними двумя периодами;
- Выводит итоговую таблицу в консоль.

## 🧩 Структура данных

Пример структуры Excel-файла (`Металлы.xlsx`):

| Лист Excel | Колонки | Пример данных |
|-------------|----------|----------------|
| Медь | Дата, Цена | `01 января 2025`, `1320.5 руб/кг` |
| Алюминий | Дата, Цена | `01 января 2025`, `215.8 руб/кг` |
| Олово | Дата, Цена | `01 января 2025`, `2760.0 руб/кг` |
| Никель | Дата, Цена | `01 января 2025`, `1750.4 руб/кг` |

## 🔗 Источники данных

- [Цены на никель](https://monetka.com.ru/quotes-metal/?m=Nickel&v=kg)  
- [Цены на медь](https://monetka.com.ru/quotes-metal/?m=Copper&v=kg)  
- [Цены на алюминий](https://monetka.com.ru/quotes-metal/?m=Aluminium&v=kg)  
- [Цены на олово](https://monetka.com.ru/quotes-metal/?m=Tin&v=kg)

## ⚙️ Использование

1. Скачайте данные с указанных страниц и сохраните их в Excel-файл с именем `Металлы.xlsx`.
2. Укажите путь к файлу в переменной `path`:
   ```python
   path = r"C:\Users\<имя_пользователя>\Desktop\Металлы.xlsx"
   ```
3. Запустите скрипт:
   ```bash
   python main.py
   ```
4. В консоли отобразится сводная таблица, содержащая:
   - средние месячные значения;
   - последние котировки;
   - процентную динамику.
