# Анализ данных о заработной плате в Российской Федерации

Этот скрипт выполняет обработку и анализ статистических данных о заработной плате по России, выгруженных с официального сайта [Федеральной службы государственной статистики (Росстат)](https://fedstat.ru/indicator/57824).

## 📄 Описание

Скрипт предназначен для расчёта **средних значений заработной платы по годам** на основе данных, предварительно выгруженных с сайта Росстата.  
Данные берутся из Excel-файла после фильтрации на сайте с выбором параметра:

> *«Российская Федерация без учета новых субъектов (с 01.01.2023)»*

## ⚙️ Шаги работы

1. На сайте [fedstat.ru/indicator/57824](https://fedstat.ru/indicator/57824) выберите соответствующий фильтр и выгрузите данные в формате **Excel (.xls)**.
2. Сохраните файл, например, как `data.xls` (или под любым другим именем).
3. Укажите путь к файлу в переменной `path` внутри скрипта:
   ```python
   path = r"C:\Users\<имя_пользователя>\Downloads\data.xls"
   ```
4. Запустите скрипт:
   ```bash
   python main.py
   ```

## 🧮 Что делает скрипт

- Читает Excel-файл начиная с **четвёртой строки заголовка** (параметр `header=3`).
- Переименовывает колонку `Unnamed: 1` → `Месяц`.
- Удаляет строки, в которых в колонке «Месяц» встречаются диапазоны (например, `январь-февраль`).
- Устанавливает колонку «Месяц» в качестве индекса.
- Оставляет **три последние колонки с годовыми значениями**.
- Рассчитывает среднее значение по каждому году и округляет результат до двух знаков.
- Выводит итоговую таблицу с колонками:
  - `Год`
  - `ЗП` — среднее значение заработной платы.

## 📊 Пример результата

```
    Год      ЗП
0  2021  57632.45
1  2022  61210.87
2  2023  65480.12
```
